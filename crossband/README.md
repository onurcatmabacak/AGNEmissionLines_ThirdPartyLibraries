# `crossband` — cross-band line ratios (Docker)

Compute ratios with uncertainties against broad physical priors.

## Run

```bash
bash pipeline/build_images.sh crossband
.venv/bin/python pipeline/run_new_tools.py --only synthetic_multiband_z_0.0000 --tools crossband --force
.venv/bin/python pipeline/run_new_tools.py --only NGC253_z_0.0008 --tools pahfit_mir fir_linefit crossband --force
```

The NGC 253 and NGC 4151 catalogues are generated by
`pipeline/build_crossband_from_outputs.py` from the real PAHFIT MIR features
and real PACS FIR lines.  NGC 4151 is the AGN validation (Seyfert 1).

Ratios: Paα/Hα, Brγ/Hα, [OIII]88/[OIII]5007, [NeIII]/[NeII],
[SIII]18.7/[SIII]33.5, [CII]/[OI]63 and [CII]/[NII]122.

## Real results

NGC 253:

| ratio | value | expected | consistent |
|---|---:|---|---|
| [NeIII]/[NeII] | 1.40 | 0.1–5.0 | yes |
| [SIII]18.7/[SIII]33.5 | 0.50 | 0.5–5.0 | yes (boundary tolerance) |
| [CII]/[OI]63 | 7.03 | 1–20 | yes |

NGC 4151 (AGN):

| ratio | value | expected | consistent |
|---|---:|---|---|
| [NeIII]/[NeII] | 0.059 | 0.1–5.0 | no (flagged) |
| [CII]/[NII]122 | 12.17 | 1–20 | yes |

## Remaining limitations

* Expected ranges are broad priors, not model predictions.
* Apertures differ between MIR and FIR; ratios are only meaningful for
  comparable regions.
* PAHFIT feature errors are approximated at 10 % in the generated catalogue.
