# crossmission — 3C120_z_0.0330

Same-object comparison of the X-ray Fe K-alpha line with the UV/optical
emission line measured by `pyqsofit_uv`.

* X-ray: `outputs/3C120_z_0.0330/rxte_xspec/rxte_lines.csv`, production row
* Optical: `outputs/3C120_z_0.0330/pyqsofit_uv/pyqsofit_lines.csv`, line **Hbeta**
* Quality: **provisional** — optical H-beta/[O III] model range 1.55-3.00 spans >1.5x; model systematic dominates

This is a consistency comparison, not a correlation fit.  See
`docs/OUTPUT_SCHEMA.md` and `docs/CAVEAT_MATRIX.md` for the repository contract.
