# crossmission — PDS456_z_0.1840

Same-object comparison of the X-ray Fe K-alpha line with the UV/optical
emission line measured by `pyqsofit_uv`.

* X-ray: `outputs/PDS456_z_0.1840/xmm_xspec/xmm_lines.csv`, production row
* Optical: `outputs/PDS456_z_0.1840/pyqsofit_uv/pyqsofit_lines.csv`, line **CIV1549**
* Quality: **tentative** — public HST/STIS spectrum covers C IV but not H-beta or Mg II; broad C IV is blended/absorption-affected and has S/N < 3

This is a consistency comparison, not a correlation fit.  See
`docs/OUTPUT_SCHEMA.md` and `docs/CAVEAT_MATRIX.md` for the repository contract.
