# PDS 456 — raw SAS 22.1 PN reduction

This directory contains the **raw ODF** PN reduction, independent of the
official PPS products used by `../xmm_xspec`.

## Reduction

- ODF: XMM-Newton ObsID `0721010201`, downloaded from the XMM-Newton Science
  Archive (not committed; 297 MB).
- SAS **22.1.0** (`xmmsas_20241108_1150-21.0.0` upstream line is PPS; this run used
  SAS 22.1.0), HEASoft/XSPEC base.
- `odfingest` → `cifbuild` → `epproc instexpids=PNS003` (full run, exit 0).
- `especget` on the **final** `*_ImagingEvts.ds` (not the intermediate
  `*_Evts.ds`, which has an unfinalized exposure and causes the SAS
  `EXPOSURE=inf`/`bad float to string` error).
- Source region: 20″ circle at detector `X,Y = 26851.0, 27749.8`.
- Background: 40–60″ annulus at the same centre.
- RMF: `epn_e2_lw20_sdY9_v22.0.rmf` (CCF v22.0); ARF generated by SAS.
- PN only, 0.5–10 keV.

## Products

| file | content |
|---|---|
| `pn_raw_src.ds` | raw PN source spectrum, 293,383 counts, 100.4 ks |
| `pn_raw_bgd.ds` | raw PN background, 27,103 counts |
| `pn_raw_src.arf` | SAS-generated ARF |
| `pn_raw_src.rmf` | XMM CCF PN response |
| `raw_fit_summary.json` | XSPEC `tbabs*zpowerlw` baseline + `zgauss` fit |
| `pn_raw_spectrum.png/pdf` | raw count spectrum |

## Fit

`tbabs*zpowerlw` (0.5–10 keV):
χ²/dof = 3004.37/1901 = 1.58, Γ = 2.100, N_H = 2.48×10²¹ cm⁻².

Adding a fixed 50 eV Fe Kα at 6.4 keV rest:
χ²/dof = 2990.34/1900, **Δχ² = 14.03 (1 dof, 3.74σ)**,
line flux = (2.15 ± 0.57)×10⁻¹⁴ erg cm⁻² s⁻¹.

The independent PPS joint PN+MOS result is Δχ² = 16.39 (4.05σ).  The raw
PN-only result is consistent in flux and significance within the different
aperture/filter choices.

## Honest caveats

- PN-only, not the joint PN+MOS fit.
- 20″ custom region, not the PPS 40″ extraction.
- The RMF is CCF v22.0 while the reduction is SAS 22.1.
- Pile-up and pattern selection are not yet optimized; run `epatplot` and a
  pattern-0/core-region check before publication.
- The raw ODF is intentionally not committed; the ODF/CCF retrieval step is
  documented in `Tools/xmm_sas_raw/README.md`.
